# 汉化内容覆盖判定

## 开工盘点

批量翻译前，从资源包、关卡引用和代表性原版画面对照，确认目标平台、版本和语言下，文字、预录播片和游戏内语音分别从哪里读取、如何显示。文本表和实机抽查支持目标范围走常规文本汉化时，采用文本回填。发现图中文字、缺字幕的播片或只有语音的对白时，按实际需要组合方案。续跑时复用已有清单和证据。

从可导出的资源和关卡引用主动查找后期关卡、支线、结局及可放大的阅读界面。用实机补查运行时拼接、随状态切换或工具无法导出的内容。抽查结论只说明实际覆盖范围。

## 选择回填方式

- **可回填文本。** 提取原文并核对实际显示入口。动态拼接内容检查完整显示结果。已有字幕的内容直接汉化字幕文本，沿用原字幕入口及可复用的时序，无需额外核听、转录或处理配音。仅对确认有语音但没有字幕的内容采用下述语音处理方案。
- **图中文字。** 批量导出候选贴图和图集做缩略图浏览，必要时按关卡、模型和实机画面反查。OCR 辅助定位和转录，人工核对像素字、手写字和破损印刷。按资源 ID 和文字区域记录原图、原文和已知场景。海报、报纸可按版头、正文、图注分条，使用同一套术语和翻译校对流程。重排固定图字并保留底纹、插图和边框，动态姓名、赏金等回填对应文本或模板。实测近看、放大和阅读界面中的可读性、位置及裁切。
- **预录播片缺字幕。** 建立播片清单，提取音轨或从隔离测试副本录制。转录后人工听校，再制作按播片时间对齐的中文字幕。优先采用验证可行的原生字幕轨。按播放器能力评估能识别影片和播放进度的字幕伴侣，或由安装器在玩家本地生成兼容原播放器的带字幕替换片。实测同步、暂停、跳过、重播及切回窗口。
- **游戏内对白只有语音。** 按语音资源或事件 ID 记录原文转录、译文和已知场景。优先依据已验证的播放事件显示字幕，语音结束、被打断或切场景时清除。找不到事件入口时，只有样本验证可靠才采用音频指纹。实测分支、打断和适用时的重叠语音。同步入口待验证时，记录当前能转录或翻译的实际范围。

## 样包与覆盖记录

在项目内维护覆盖清单。每项记录稳定 ID、来源、图像区域或时间轴、已知关卡或分支、选用方案和证据。分别记录已发现、已翻译、已回填、已实机验证。无法导出的素材、未识别的语音、未到达的分支及未验证的字幕入口保留为待查项。

依照 [汉化排版预检](layout-qa.md)，对实际采用的每种显示方式选一个代表场景，在隔离测试副本中验证可行性，再批量应用对应方案。最终用正式译文复测已实现的路径，发布说明据此列出已覆盖和待查范围。
