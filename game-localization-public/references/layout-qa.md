# 汉化排版预检与回归

1. 批量翻译前，在隔离测试副本中用计划发布的字体和实际游戏的文字渲染路径制作可运行的中文样包。选取短标签、长提示、中英数字混排、多行对白和带变量的文本。
   按内容覆盖清单，为每种实际采用的显示方式选一个代表场景。有图中文字或新增字幕时，实测可读性、显示位置，以及适用时的播放同步。
2. 在相同窗口尺寸和界面状态下截取原版与样包画面。优先检查标题、设置、存档槽、弹窗、按键提示、对白选项及本作特有界面。至少检查默认显示尺寸，游戏支持时再检查一个较小窗口或不同 UI 缩放档位。
3. 逐项核对文字基线、对齐、换行、裁切和与边框或图标的重叠。实际触发短标签变长、动态数值变化、继续变确认等状态切换。确认样例能覆盖共用控件及关键个别界面。
4. 定位错位来自字体度量、共用控件还是个别界面。修正后复查同类控件，保存原版、修复前后截图及复现步骤。代表性界面通过后，再批量应用排版方案。遇到无法实机验证的场景，记录具体原因和待测范围。
5. 正式打包前，用最终补丁重跑样例场景和已修复问题，并用真实译文检查最长标签、动态数值和状态切换。用正式译文复查各显示方式，记录已实测与未覆盖的场景。有条件时把已复现的问题加入回归检查。
